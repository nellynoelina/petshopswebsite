Pet Shop Website 

A full-stack e-commerce web application for an online pet shop, built as a university project. Users can browse products, manage a shopping cart, check out, and contact the shop, while admins can manage the store through a dedicated dashboard.

Features
User authentication — registration, login, and logout with session handling
Product browsing — view all products and individual product details
Shopping cart — add, view, and remove items from the cart
Checkout & orders — place orders from the cart
Admin dashboard — manage the store (products, orders, etc.)
Contact form — send messages to the shop
Database-backed — all product, user, and order data stored and retrieved dynamically

Tech Stack
Backend: PHP
Database: MySQL
Frontend: HTML, CSS, JavaScript
